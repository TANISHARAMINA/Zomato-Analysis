Zomato Restaurants Data Analysis:

Project Definition:
This project analyzes the Zomato Restaurants dataset using Python to understand restaurant ratings, cuisines, price ranges, and customer preferences.  
The goal is to extract meaningful insights about restaurant trends and customer behavior.



Dataset Usecase:
Source: Kaggle – Zomato Restaurants Dataset  
Use Cases:
- Identify popular cuisines and cities with the highest number of restaurants  
- Study the relationship between price range and ratings  
- Analyze the impact of online delivery on ratings  
- Explore the correlation between votes and ratings  


Visualization Graphs and Outcomes:
1. **Rating Distribution** → Most restaurants have ratings between 3–4  
2. **Top Cuisines** → North Indian and Chinese are the most popular  
3. **City‑wise Count** → Delhi has the highest number of restaurants  
4. **Price Range vs Rating** → Moderate price restaurants tend to have better ratings  
5. **Online Delivery vs Rating** → Restaurants with online delivery show slightly better ratings  
6. **Votes vs Rating** → Restaurants with higher votes generally have higher ratings  



 Python Libraries / Tools:
- **pandas** → Data cleaning and manipulation  
- **matplotlib** → Graph plotting  
- **seaborn** → Advanced and stylish visualizations  
- **numpy** → Numerical operations  


 Repository Contents:
- `Zomato_Analysis.ipynb` → Jupyter/Colab notebook with code and visualizations
